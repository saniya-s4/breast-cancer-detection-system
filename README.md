# 🎗️ Breast Cancer Detection System

A machine learning-based web application that predicts whether a breast tumor is **benign or malignant** based on patient diagnostic features.

## 🚀 Features

* Machine learning-based breast cancer prediction
* Simple and user-friendly Streamlit interface
* Takes diagnostic features as input
* Displays the prediction result instantly
* Uses a trained ML pipeline for prediction

## 🛠️ Technologies Used

* **Python**
* **Scikit-learn**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Streamlit**
* **Joblib**

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/saniya-s4/breast-cancer-detection-system.git
cd breast-cancer-detection-system
```

Create and activate a virtual environment:

```bash
python -m venv ev1
```

Windows:

```bash
ev1\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app1.py
```

The application will open in your browser.

## 🧠 Machine Learning

The application uses a trained machine learning pipeline stored in:

```text
best_pipe.joblib
```

The model processes the provided diagnostic features and generates a classification result.
